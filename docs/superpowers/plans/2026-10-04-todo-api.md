# Todo API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Jakarta EE 10 REST API on Open Liberty that does in-memory CRUD on Todo tasks.

**Architecture:** One WAR with four classes in `com.example.todo`. `TaskRepository` is an `@ApplicationScoped` CDI bean that holds tasks in a `ConcurrentHashMap`. `TaskResource` is a JAX-RS resource that validates input, calls the repository and maps results to HTTP status codes. JSON-B converts between JSON and Java. Liberty dev mode (`./mvnw liberty:dev`) runs it.

**Tech Stack:** Java 21 (release level, compiled with the installed JDK 25), Jakarta EE 10 Web Profile API, Open Liberty, Maven 3.9.16 via Maven Wrapper 3.3.4, JUnit 5.14.4.

**Spec:** `docs/superpowers/specs/2026-10-04-todo-api-design.md`

## Global Constraints

- Dependency `jakarta.platform:jakarta.jakartaee-web-api:10.0.0`, scope `provided`.
- Liberty features exactly: `restfulWS-3.1`, `jsonb-3.0`, `cdi-4.0`.
- Maven is not installed globally. Every build command goes through `./mvnw` (Git Bash) or `mvnw.cmd` (PowerShell).
- `war` packaging. `maven.compiler.release` = `21`.
- Storage is in memory only. No database, no JPA, no Bean Validation, no auth.
- HTTP port `9080`, context root `/`, application path `/api`.
- Package `com.example.todo`.
- Error responses have the JSON body `{"error": "<message>"}`.
- The server always assigns `id`. Any `id` in a POST/PUT body is ignored.
- `findAll()` returns tasks sorted by id, ascending.

## Review Focus

1. **The client sends an `id` in the body** (`{"id": 99, "title": "x"}`): create still assigns the next id, and update keeps the id from the path. This is pinned by repository unit tests in Task 2.
2. **Many clients create tasks at the same time:** every task gets a unique id and none are lost. This is pinned by a concurrent-create unit test in Task 2.
3. **The title is only whitespace** (`"   "`): POST and PUT return 400, not 201/200. This is pinned by curl checks in Task 3.
4. **The id in the path is not a number** (`GET /api/tasks/abc`): 404, not 500. This is pinned by a curl check in Task 3.
5. **The body is malformed JSON or empty:** 400, not 500. This is pinned by curl checks in Task 3.

- [ ] **Step 1: Write the failing tests**

`src/test/java/com/example/todo/TaskRepositoryTest.java`:

```java
package com.example.todo;

import static org.junit.jupiter.api.Assertions.*;

import java.util.HashSet;
import java.util.List;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.TimeUnit;

import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;

class TaskRepositoryTest {

    private TaskRepository repo;

    @BeforeEach
    void setUp() {
        repo = new TaskRepository();
    }

    @Test
    void createAssignsIncreasingIds() {
        Task a = repo.create(new Task("a", false));
        Task b = repo.create(new Task("b", true));
        assertEquals(1L, a.getId());
        assertEquals(2L, b.getId());
        assertEquals("b", b.getTitle());
        assertTrue(b.isDone());
    }

    @Test
    void createIgnoresClientSuppliedId() {
        Task input = new Task("a", false);
        input.setId(99L);
        Task created = repo.create(input);
        assertEquals(1L, created.getId());
        assertTrue(repo.findById(99L).isEmpty());
    }

    @Test
    void findByIdReturnsExistingTask() {
        Task created = repo.create(new Task("a", false));
        assertEquals("a", repo.findById(created.getId()).orElseThrow().getTitle());
    }

    @Test
    void findByIdReturnsEmptyForMissingId() {
        assertTrue(repo.findById(42L).isEmpty());
    }

    @Test
    void updateChangesExistingTaskAndKeepsPathId() {
        Task created = repo.create(new Task("a", false));
        Task changes = new Task("b", true);
        changes.setId(99L);

        Task updated = repo.update(created.getId(), changes).orElseThrow();

        assertEquals(created.getId(), updated.getId());
        assertEquals("b", updated.getTitle());
        assertTrue(updated.isDone());
        assertEquals("b", repo.findById(created.getId()).orElseThrow().getTitle());
        assertTrue(repo.findById(99L).isEmpty());
    }

    @Test
    void updateReturnsEmptyForMissingId() {
        assertTrue(repo.update(42L, new Task("b", true)).isEmpty());
        assertTrue(repo.findAll().isEmpty());
    }

    @Test
    void deleteRemovesExistingTask() {
        Task created = repo.create(new Task("a", false));
        assertTrue(repo.delete(created.getId()));
        assertTrue(repo.findById(created.getId()).isEmpty());
    }

    @Test
    void deleteReturnsFalseForMissingId() {
        assertFalse(repo.delete(42L));
    }

    @Test
    void findAllIsSortedByIdAscending() {
        for (int i = 0; i < 20; i++) {
            repo.create(new Task("t" + i, false));
        }
        repo.delete(5L);
        List<Long> ids = repo.findAll().stream().map(Task::getId).toList();
        assertEquals(ids.stream().sorted().toList(), ids);
        assertEquals(19, ids.size());
    }

    @Test
    void concurrentCreatesGetUniqueIds() throws InterruptedException {
        int count = 1000;
        Set<Long> ids = ConcurrentHashMap.newKeySet();
        ExecutorService pool = Executors.newFixedThreadPool(8);
        for (int i = 0; i < count; i++) {
            pool.submit(() -> ids.add(repo.create(new Task("t", false)).getId()));
        }
        pool.shutdown();
        assertTrue(pool.awaitTermination(10, TimeUnit.SECONDS));

        assertEquals(count, ids.size());
        assertEquals(count, repo.findAll().size());
        assertEquals(new HashSet<>(ids), new HashSet<>(repo.findAll().stream().map(Task::getId).toList()));
    }
}
```

`src/main/java/com/example/todo/TaskRepository.java`:

```java
package com.example.todo;

import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicLong;

import jakarta.enterprise.context.ApplicationScoped;

@ApplicationScoped
public class TaskRepository {

    private final Map<Long, Task> tasks = new ConcurrentHashMap<>();
    private final AtomicLong nextId = new AtomicLong(1);

    public List<Task> findAll() {
        return tasks.values().stream()
                .sorted(Comparator.comparing(Task::getId))
                .toList();
    }

    public Optional<Task> findById(Long id) {
        return Optional.ofNullable(tasks.get(id));
    }

    public Task create(Task task) {
        Task stored = new Task(task.getTitle(), task.isDone());
        stored.setId(nextId.getAndIncrement());
        tasks.put(stored.getId(), stored);
        return stored;
    }

    public Optional<Task> update(Long id, Task task) {
        return Optional.ofNullable(tasks.computeIfPresent(id, (key, existing) -> {
            Task replaced = new Task(task.getTitle(), task.isDone());
            replaced.setId(key);
            return replaced;
        }));
    }

    public boolean delete(Long id) {
        return tasks.remove(id) != null;
    }
}
```

- [ ] **Step 1: Write `TaskResource`**

`src/main/java/com/example/todo/TaskResource.java`:

```java
package com.example.todo;

import java.net.URI;
import java.util.List;
import java.util.Map;

import jakarta.inject.Inject;
import jakarta.ws.rs.Consumes;
import jakarta.ws.rs.DELETE;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.POST;
import jakarta.ws.rs.PUT;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.PathParam;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.Context;
import jakarta.ws.rs.core.MediaType;
import jakarta.ws.rs.core.Response;
import jakarta.ws.rs.core.UriInfo;

@Path("/tasks")
@Produces(MediaType.APPLICATION_JSON)
@Consumes(MediaType.APPLICATION_JSON)
public class TaskResource {

    @Inject
    TaskRepository repository;

    @GET
    public List<Task> list() {
        return repository.findAll();
    }

    @GET
    @Path("/{id}")
    public Response get(@PathParam("id") Long id) {
        return repository.findById(id)
                .map(task -> Response.ok(task).build())
                .orElseGet(() -> notFound(id));
    }

    @POST
    public Response create(Task task, @Context UriInfo uriInfo) {
        if (isInvalid(task)) {
            return badRequest();
        }
        Task created = repository.create(task);
        URI location = uriInfo.getAbsolutePathBuilder().path(created.getId().toString()).build();
        return Response.created(location).entity(created).build();
    }

    @PUT
    @Path("/{id}")
    public Response update(@PathParam("id") Long id, Task task) {
        if (isInvalid(task)) {
            return badRequest();
        }
        return repository.update(id, task)
                .map(updated -> Response.ok(updated).build())
                .orElseGet(() -> notFound(id));
    }

    @DELETE
    @Path("/{id}")
    public Response delete(@PathParam("id") Long id) {
        return repository.delete(id)
                ? Response.noContent().build()
                : notFound(id);
    }

    private static boolean isInvalid(Task task) {
        return task == null || task.getTitle() == null || task.getTitle().isBlank();
    }

    private static Response badRequest() {
        return error(Response.Status.BAD_REQUEST, "title must not be blank");
    }

    private static Response notFound(Long id) {
        return error(Response.Status.NOT_FOUND, "task " + id + " not found");
    }

    private static Response error(Response.Status status, String message) {
        return Response.status(status)
                .type(MediaType.APPLICATION_JSON)
                .entity(Map.of("error", message))
                .build();
    }
}
```

```java
package com.example.todo;

import java.util.Map;

import jakarta.json.bind.JsonbException;
import jakarta.ws.rs.core.MediaType;
import jakarta.ws.rs.core.Response;
import jakarta.ws.rs.ext.ExceptionMapper;
import jakarta.ws.rs.ext.Provider;

@Provider
public class JsonErrorMapper implements ExceptionMapper<JsonbException> {

    @Override
    public Response toResponse(JsonbException e) {
        return Response.status(Response.Status.BAD_REQUEST)
                .type(MediaType.APPLICATION_JSON)
                .entity(Map.of("error", "malformed JSON"))
                .build();
    }
}
```
